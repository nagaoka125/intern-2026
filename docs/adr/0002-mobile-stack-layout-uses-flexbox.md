# スマートフォン幅の縦積みレイアウトは CSS Grid ではなく Flexbox を使う

デスクトップのレイアウトは CSS Grid で組んでいるが、600px 以下で動画・コメント・送信領域を縦積みにするレイアウトだけは意図的に Flexbox に切り替えている。`grid-template-rows: auto` な行に `aspect-ratio` 指定を持つ動画エリアを置くと、Grid の行の自動サイズ計算が実際の描画高さより小さく見積もられ、直下のコメント見出し「コメント」が動画と重なって見切れる不具合が発生することを実測（Chromium）で確認した。Flexbox による縦積みではこの不具合が発生しない。

デスクトップと実装技術を揃えるために縦積み側も Grid に統一すると、このコメント見出しが動画に重なる不具合が再発するため、統一しないこと。
