# 折りたたみ系の0fr指定は、行・列問わず `minmax(0, 0fr)` にする

コメント表示欄を非表示にする際、その列の `grid-template-columns` を `0fr` にして幅を0に潰す実装にしたが、実測したところ幅が0にならず、見出しの文字幅ぶん（十数px）だけ残ってしまうことを確認した。CSS Grid の仕様上、裸の `<flex>` 値（`0fr` など）をトラックサイズとして使うと暗黙の最小サイズが `auto` 扱いになり、中身（この場合は「コメント」という見出しテキスト）の最小コンテンツサイズまでしか縮まらないため。`minmax(0, 0fr)` と明示することで、最小サイズを実際に0にできる。

この問題は `grid-template-columns` だけでなく `grid-template-rows` でも同様に起きる。アイテムパネル・コメント欄（モバイル）・送信欄の折りたたみアニメーションでも同じ理由で完全に0にならない箇所が見つかり、いずれも `minmax(0, 0fr)` に修正した。折りたたみ系のグリッドトラックを新たに追加する際は、最初から `minmax(0, 0fr)` を使うこと。

`0fr` に「簡略化」すると、対象の要素が完全には隠れず、細い帯として残る不具合が再発するため注意すること。
