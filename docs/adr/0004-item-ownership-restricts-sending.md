# アイテム送信は所持数のある物だけに制限する

アイテム獲得機能を追加するにあたり、「抽選で当たったことを記録するだけ」（送信自体はこれまで通り全アイテムから自由に選べる）にするか、「所持数のあるアイテムしか送信できない所有制」にするかを検討した。コレクション記録方式の方が既存の送信仕様への影響は小さいが、ポイントを貯めて抽選するという行為に実質的な意味を持たせるため、所有制を採用した。結果として、初見のアイテムは所持数10からスタートし、送信のたびに1消費、抽選当選で1増加する仕組みになっている（詳細は [CONTEXT.md](../../CONTEXT.md) の「所持数」を参照）。

## Consequences

送信できるアイテムが視聴者ごとに変動するため、アイテムパネルの表示（残数・選択可否）が状態を持つようになる。将来「全アイテムを常に自由に送れる」仕様に戻す場合は、所持数チェックを外すだけで済む。
