# ポイント・所持数は localStorage のみで管理する

`COMMENT_MESSAGES_URL` へのリクエストにはユーザーを識別する情報（ログイン、userId など）が一切なく、アイテムサーバー側にも視聴者ごとの状態を保存する仕組みが存在しない。そのため、抽選のためのポイントとアイテムの所持数は、テーマ設定と同様に各ブラウザの `localStorage` にのみ保存することにした。サーバー側APIを拡張してユーザーごとの状態を持たせる案は、外部サービス側の変更が必要になりスコープが大きくなるため見送った。

## Consequences

ポイント・所持数はブラウザやデバイスをまたいで共有されず、ブラウザのストレージを消去すると失われる。将来、端末をまたいだ永続化が必要になった場合は、サーバー側にユーザー識別の仕組みを導入する設計変更が必要になる。
