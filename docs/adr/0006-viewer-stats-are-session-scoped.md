# 総コメント数・アイテム数はセッション限定のカウンターとする

コメントサーバーには過去ログを取得するAPIがなく、SSE（`COMMENT_EVENTS_URL`）は接続後に発生した新規イベントしか配信しない。そのため「総コメント数」「アイテム数」は、ページを開いてSSE接続を確立してから受信したイベントをクライアント側でカウントするだけの値とし、`localStorage`等への永続化も行わないことにした。サーバー側に過去件数を返すAPIを追加してもらう案は、外部サービス側の変更が必要でスコープが大きくなるため見送った。

## Consequences

表示される件数はあくまで「今このページを開いてから」の累計であり、配信全体の本当の総数ではない。ページを再読み込みすると0から数え直しになり、複数タブ・複数端末間でも共有されない。将来、配信全体の正確な総数を出したくなった場合は、コメントサーバー側に累計件数を返すAPIを追加してもらう必要がある。
