# チャンネル切替時にコメント欄と視聴統計をリセットする

コメントサーバー・アイテムサーバーはチャンネルに依存しない共通のエンドポイントであり、SSE接続（`COMMENT_EVENTS_URL`）はチャンネルを切り替えても張り直さない。それにもかかわらず、チャンネル切替時にはコメント表示領域を空にし、総コメント数・アイテム数カウンター（ADR 0006）も0にリセットすることにした。過去チャンネルのコメントが新しいチャンネルの画面に残ったままだと、視聴者にとって「今見ている配信に対するコメントなのか」が分かりにくくなるため、視覚的な区切りを優先した。

## Consequences

チャンネルを行き来するたびにコメント表示とカウンターがリセットされるため、複数チャンネルをまたいだ累計を知りたい場合には向かない。将来チャンネルごとに独立したコメント/アイテムのバックエンドを持つようになった場合は、この前提を見直す必要がある。
